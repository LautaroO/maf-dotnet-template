# MAF .NET capability matrix

Matrix version: 1.0. Template version: 4.0.0. Last verified MAF release: `dotnet-1.18.0`. Verification date: 2026-09-09.

This is discovery guidance, not an API lockfile. Verify the target repository's package versions and public API before coding. “Available” means documented for .NET at verification time; package and provider maturity can differ.

| Feature | .NET availability | Maturity | Required package/boundary | Provider or hosting restrictions | Official source | Verified release | Verified date |
|---|---|---|---|---|---|---|---|
| `AIAgent` / `ChatClientAgent` | Available | Core | `Microsoft.Agents.AI` | Provider must expose a compatible agent or `IChatClient` | [Agents](https://learn.microsoft.com/agent-framework/agents/) | dotnet-1.18.0 | 2026-09-09 |
| Sessions and history | Available | Core | `Microsoft.Agents.AI` | Persistence semantics depend on agent/provider/store | [Sessions](https://learn.microsoft.com/agent-framework/agents/conversations/session) | dotnet-1.18.0 | 2026-09-09 |
| Streaming | Available | Core/provider-dependent | `Microsoft.Agents.AI` plus provider | Update/event fidelity differs by provider | [Agents](https://learn.microsoft.com/agent-framework/agents/) | dotnet-1.18.0 | 2026-09-09 |
| Multimodal input | Available | Provider-dependent | `Microsoft.Agents.AI` plus provider | Modalities, size, URI and upload support vary | [Multimodal](https://learn.microsoft.com/agent-framework/agents/multimodal) | dotnet-1.18.0 | 2026-09-09 |
| Structured output | Available | Provider-dependent | `Microsoft.Agents.AI` / `Microsoft.Extensions.AI` | Schema fidelity and streaming vary; validate in C# | [Structured outputs](https://learn.microsoft.com/agent-framework/agents/structured-outputs) | dotnet-1.18.0 | 2026-09-09 |
