# Codex + MAF Guidance Pack 4.0.0

Historical record of an earlier revision. Release-specific knowledge/auditing was retired by the [stable-guidance amendment](../superpowers/specs/2026-10-30-stable-maf-guidance-design.md); this document does not define the current maintenance policy or MAF compatibility.

Version 4 turns the repository into a guidance-only capability pack for existing C#/.NET applications and AI-first repositories. It adds adoption, hosting, and security skills; a verified .NET capability matrix; 17 uniform implementation playbooks; routing fixtures; stronger review requirements; CI; and a non-mutating scheduled source audit.

The default adoption recommendation is an application-centric root with MAF guidance scoped to its AI subtree. AI-first placement remains available where MAF genuinely owns central orchestration.

This release has no installer, plugin, application scaffold, runtime Agent Skill bundle, or compilable sample. C# fragments are illustrative and must be reconciled with installed NuGet APIs.

Template version: `4.0.0`. Last verified MAF .NET release: `dotnet-1.18.0`. Verification date: 2026-09-09.

PR review, corrections, and representative fresh-session results for both profiles are recorded in [the review evidence](../reviews/pr-1.md). These results do not replace a full routing evaluation or publish a GitHub release.
